# 0.3.7 내 기록 저장과 퍼센트 표시

HP 퍼센트는 소수점 둘째 자리까지 반올림해 표시합니다. 예: `99.99999615% → 100.00%`, `52.3456% → 52.35%`. 정수 HP·피해·기여도와 서버 산식은 그대로입니다.

## 로그인 없는 기록 유지

기존 익명 플레이어 식별자를 재사용하며, GPS와 가상 모드의 개인 기록을 기기 안에 따로 저장합니다. 이름·누적 유효 걸음·포인트·공략 성공·칭호·장비·최근 공략 지역·마지막 확인 기여 등을 저장합니다. 시작 화면에서 저장된 걸음·포인트·최근 공략 기여를 확인할 수 있습니다.

이전에는 닉네임과 플레이어 식별자만 저장했고, 재접속하면 공략 대상을 선택하지 않은 화면으로 돌아갔습니다. 0.3.7은 서버에서 확인한 개인 기록의 로컬 사본을 추가로 보관합니다. 온라인 연결 후에는 기존 플레이어의 서버 기록을 다시 읽습니다.

1. 앱 시작 화면에서 저장된 모드별 내 기록을 확인합니다.
2. GPS 또는 가상 이동을 선택합니다.
3. 지도 상단의 **이전 공략 이어하기**를 눌러 마지막 지역을 다시 선택합니다.
4. GPS 모드는 새로운 현재 위치가 선택 지역 안에 있는지 확인한 뒤 공략을 시작합니다.

저장된 기록을 보는 것만으로 이동·피해를 만들거나 GPS 추적을 재개하지 않습니다. 로컬 기록은 마지막으로 서버에서 확인한 사본이며, 공략 HP·랭킹·보상·구매의 기준은 서버입니다. 최근 공략이 다른 사람에 의해 완료됐다면 이어하기 시 새 몬스터의 현재 기록을 받습니다.

일반 앱과 별도 진단 앱은 서로 다른 설치이므로 플레이어와 저장소도 분리됩니다. 앱을 삭제하거나 앱 데이터를 지우면 로그인 없이 보관한 기기 식별자와 로컬 사본도 없어질 수 있습니다. 기존 앱 위에 업데이트 설치하면 그대로 이어집니다.

이 버전 설치 전의 과거 로컬 사본은 없으므로, 첫 연결에서 같은 플레이어의 서버 기록을 확인해 저장합니다. 이전 버전에서 선택했던 지역은 다시 선택해야 할 수 있습니다. 이후부터 마지막 공략 지역을 로컬에서 복원합니다.
