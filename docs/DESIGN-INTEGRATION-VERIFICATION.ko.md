# 디자인 통합 검증 기록 — 2026-09-20

이 문서는 Expo 57 `mobile/` 앱의 원본 WalkWar 디자인 통합 결과를 기록합니다. 기존 [검증 기록](VERIFICATION.md)은 유지하며, 이 문서는 디자인 통합 검증 범위만 추가합니다.

## 확인한 통합 범위

- Expo 원본 `GlassPanel`, `LiquidSurface`, `UI`, `theme`, `preferences` 컴포넌트와 상태를 재사용했습니다.
- 전국 행정구역 API와 실제 게임 서버 연결을 확인했습니다.
- 타입검사와 앱·지도·클라이언트 테스트 12개가 통과했습니다.
- 서버 테스트 27개는 이전 검증에서 통과했으며, `liveGameClient` 스모크도 통과했습니다.
- Android `assembleDebug`와 arm64-v8a·x86_64 standalone release 빌드가 통과했습니다.
- `emulator-5580`에 업데이트 설치 후 기존 닉네임 `전국테스터`와 기존 진행도를 유지하는 것을 확인했습니다.

## 화면과 게임 흐름

- 지도에서 서울 국기를 탭하면 지역 설명과 마지막 포획 기록이 표시되고, `공략 시작`을 눌러야 진행이 시작됩니다.
- 지도 확대 레벨 4.2에서 오버레이가 0개이며 원래 표시되던 `지역 n개`가 나타나지 않습니다.
- 실제 60P로 배지를 구매해 270P에서 210P로 감소하고, 구매한 배지를 장착했습니다.
- 칭호를 해제한 뒤 다시 장착하는 흐름을 확인했습니다.
- GPS 위치와 활동 권한을 허용한 뒤 걸음 센서가 없는 상태에서 해당 안내가 표시되는 것을 확인했습니다.
- 가상 조이스틱을 6초간 스와이프하면 총 걸음이 175에서 197로, x 좌표가 60에서 77.013으로 증가했습니다. 손을 뗀 뒤 재조회해도 총 걸음 197이 유지됐습니다.
- 이어지는 공략 완료 시 내 기여 22와 +100P 보상 시트를 확인했습니다.

## 한계와 재현 조건

- 실제 Android 기기를 들고 걷는 물리 GPS·걸음 센서는 아직 검증하지 않았습니다.
- Android는 blur 기반 대체 표현을 사용하며, iOS에서 실제 Apple Glass 효과가 동작하는지는 검증하지 않았습니다.
- 외부 지도 타일과 로컬 게임 서버가 필요합니다.
- 산출물은 내부 테스트용 디버그 키로 서명했으며 JavaScript를 포함해 Metro 없이 실행되는 APK입니다.

따라서 위 결과는 지정된 에뮬레이터와 로컬 서버를 사용한 통합 검증 기록이며, 실물 보행이나 배포용 서명 검증을 의미하지 않습니다.
