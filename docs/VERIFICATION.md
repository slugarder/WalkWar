## 실제 기기로 확인해야 할 범위

물리적인 Android 휴대폰 보행은 아직 검증하지 않았습니다. GPS 수신, 기기 TYPE_STEP_COUNTER 지원과 지연, 제조사별 권한/전경 전환을 실제 기기로 확인해야 합니다. API에 좌표와 센서 값을 넣는 테스트를 실제 보행 검증으로 간주하지 않습니다. 백그라운드 보행 추적은 이번 구현 범위가 아닙니다.

지도 타일은 인터넷 연결이 필요하며 최근 타일은 로컬 캐시를 사용합니다. 행정 경계와 점령 정보는 로컬 게임 서버에서 제공합니다. 지도 배경이 없더라도 경계 조회를 GPS 위치로 간주하거나 임의 경계를 생성하지 않습니다.
