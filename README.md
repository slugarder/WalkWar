# WalkWar 전국 레이드

0.3.7(code 10)은 HP 퍼센트를 소수점 둘째 자리까지 표시하고, 로그인 없이 기기 안에 모드별 내 기록을 저장합니다. 재실행 시 저장 기록을 보여주며, 연결 후 **이전 공략 이어하기**로 최근 지역을 다시 선택할 수 있습니다. GPS 공략은 현재 위치를 다시 확인합니다. 실제 HP와 서버의 피해 계산은 변경하지 않습니다.

0.3.6(code 9)은 인구·행정 체급별 체력을 적용합니다. 반올림 없이 계산하고 상위 체급의 최저 체력은 하위 체급 최고 체력의 10배 이상입니다. 기존 공략의 피해·기여·점령 기록을 유지합니다. 자세한 산식과 전환 방식은 [체력 적용 안내](docs/POPULATION-HP.ko.md)를 참고하세요.

0.3.5(code 8)는 사용자가 지정한 `KakaoTalk_20260920_211624092.png`를 앱 아이콘으로 적용한 버전입니다. `mobile/assets/icon.png`에는 원본 PNG를 그대로 보관하고, Android 런처 리소스는 Expo 57 변환기로 각 밀도에 맞춰 생성했습니다. Android의 네이비 배경과 drawable 여백 안에 전체 로고를 표시하며 일반·진단 앱에 같은 아이콘을 사용합니다. 아이콘 재생성은 루트에서 `node scripts/Update-AndroidIcon.cjs`를 실행합니다. 전체 prebuild로 native 프로젝트를 덮어쓰지 마세요. 0.3.4의 GPS·기여·랭킹 수정은 유지되며, 이후 0.3.6에서 인구 기반 몬스터 체력을 적용했습니다.

Expo 57 기반 `mobile/` 통합 앱에 기존 WalkWar UI 컴포넌트와 전국 행정구역 공략을 연결한 개발용 APK입니다. 기존 Kotlin `android/` 프로젝트는 비교용으로 보존합니다.

1. `artifacts/WalkWar-online.apk`를 설치합니다.
2. 앱에서 GPS 또는 가상 모드만 선택합니다. 서버 주소 입력은 제공하지 않으며, 기존 서버 주소·legacy/local 설정은 자동으로 무시합니다.
3. 지도 확대·축소 → 국기 선택 → 지역 설명 → **공략 시작**.

설치 파일: `artifacts/WalkWar-online.apk`, applicationId `com.walkwar.integrated`, 실행 Activity `com.walkwar.integrated/.MainActivity`.
진단용 별도 설치 파일은 `artifacts/WalkWar-debug.apk`입니다. GPS 권한 반복 수정과 지도 경량화를 포함하며, 기기·WebView·종료 기록을 공유할 수 있습니다. [진단 앱 사용법](docs/DIAGNOSTIC.ko.md)을 참고하세요.

0.3.4(code 7)는 공략 시작 전 GPS를 다시 확인하고, `TYPE_STEP_COUNTER`의 지연 batch도 유효 지역 체류 시간으로 반영합니다. 유효 지역의 GPS 반영 허용량은 초당 4걸음씩, 최대 120걸음까지 쌓으며 stale/invalid/지역 밖/epoch·reset/gap 30초 초과와 pause 안전판은 유지합니다. 첫 센서값은 baseline으로만 사용하며 기여를 자동 부여하지 않습니다. 지도 **내 위치에서 공략**은 현재 위치에 속한 시·도 / 시·군·구 / 읍·면·동을 찾아줍니다. 지역 설명을 확인한 뒤 공략 시작을 눌러야 참여합니다. 일반판과 별도 진단판에 동일하게 적용됩니다.
온라인 APK는 `https://walkwar-production.up.railway.app`에 연결합니다. 이 패키지는 스토어 출시용 서명이 포함되지 않은 개발 버전입니다. 로컬 서버 절차는 백엔드 개발 또는 기존 로컬 APK를 위한 별도 선택 사항입니다.

## 구현한 기능

- 전국 시·도, 시·군·구, 읍·면·동. 일반구가 있는 시는 시 전체와 개별 구를 각각 선택.
- 실제 경계와 밀도에 맞춰 단계적으로 표시되는 지도. 대한민국 전체 보기에서는 시·도 국기를 개별 표시하고, 확대할수록 시·군·구와 읍·면·동으로 내려간다. 과도한 축소에서는 행정 국기·라벨·경계를 숨기며 군집 표시나 군집 선택 화면은 사용하지 않는다.
- 마지막 완료 공략의 1위 팀 국기, 동률 팀 동시 표시. 미점령 지역은 🏳️.
- 가상 조이스틱 또는 전경 GPS·기기 걸음 센서. 화면을 벗어난 동안의 걸음은 나중에 합산하지 않음. GPS·걸음 센서는 실제 기기 권한과 센서 상태를 따릅니다.
- 개인·팀 순위, 모든 완료 공략 기록, 100P 참여 보상, 배지·칭호.
- 내 기록은 순위권 여부와 지역 밖 여부에 관계없이 항상 고정 표시되며, 기여 0도 기록합니다. 랭킹 상세의 GPS `걸음 확인`은 현재 추적에서 감지한 걸음과 실제 공략 기여를 별도로 표시합니다. 추적 걸음 기준은 공략 지역 선택과 앱 복귀 때 초기화합니다.
- 실제 포인트 차감 구매, 중복 요청 방지, 장착·해제와 SQLite 저장.
- GPS/가상 모드별 지갑·칭호·장비·순위·점령 기록 분리.
